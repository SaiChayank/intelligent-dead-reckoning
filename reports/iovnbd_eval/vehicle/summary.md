# IO-VNBD GNSS-outage evaluation

Generated by `tools/iovnbd_outage_eval.py`; every number below comes from `summary.json` and `outages.csv` in this folder.

- Input: VBOX vehicle-frame yaw rate and acceleration (external IMU) + VBOX GNSS 1 Hz
- GNSS aiding: VBOX receiver fixes at 1 Hz (phone GPS was logged only every ~9 s)
- Calibration: batch mount calibration from the drive's warm-up window (phone IMU + GNSS aiding stream, no truth), released at the window end
- Engine: app CalibratingFusionEngine + FusionNavigationEngine via edge runIovnbdEval, IO-VNBD rest/straightness profile
- Gate: drift < 10 % of distance travelled during the outage
